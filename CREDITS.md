**Note on the rifle:** the Sketchfab Standard licence allows use inside a game, but not sharing the
model file on its own. Don't publish the raw `public/assets/` folder (for example in a public Git
repository) while it contains `rifel.glb`. Swapping it for a CC0 or CC BY rifle avoids the issue.
